# SGRentalBros

First clickable prototype for SGRentalBros — a mobile-first Singapore rental marketing, rental education and new-launch lead platform.

## Prototype features
- Rental-first homepage and video-first positioning
- Demo available-rental cards and filters
- Landlord rental-assessment lead form
- Tenant Rental Match form
- Rental Encyclopedia section
- New Launches section with district/tenure filters
- Bros' Recommended Crew directory concept
- Lead forms stored locally in the browser for prototype testing
- Responsive mobile navigation

## Important
Rental cards are demo content, not live advertisements. New-launch sample data must be verified before production use. The production phase should connect permitted Huttons project data, real SGRentalBros video embeds, a real lead database/CRM, WhatsApp, analytics and hosting.
